Tutorial, Group Assignment and Lab Work completed for Software Technology 2 at the University of Canberra. Each week is packaged with as a .zip file containing the full coding lab work for that session.

Requirements:
Python (3.11, or latest version)
Standard library only (no external dependencies for core modules)
'tkinter' and 'matplotlib' required for visualisation and benchmarking charts

Each week's work is packaged as a .zip file. Extract the relevant folder and run the desired module directly, which contain task-based Python modules aligned to tutorial activity sheets.
